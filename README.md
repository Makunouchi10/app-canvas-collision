# Canvas Collision App

## Overview
This is a web-based graphics demonstration project focused on HTML5 Canvas animations, including basic drawing, collision detection (`main_colision.js`), and bounce physics (`main_rebote.js`), built with a simple version (`main_simple.js`).

## Files
- **index.html**: Main HTML entry point with canvas element.
- **assets/css/style.css**: Styles for the application.
- **assets/js/main_simple.js**: Basic canvas animation.
- **assets/js/main_colision.js**: Canvas with collision detection.
- **assets/js/main_rebote.js**: Canvas with collision and bounce effects.
- **assets/img/favicon_c.png**: Favicon.

## How to Run
1. Open `index.html` in a modern web browser (Chrome, Firefox, etc.).
2. Switch between demos by modifying the script include in `index.html`:
   - Use `main_simple.js` for basic animation.
   - Use `main_colision.js` for collision detection.
   - Use `main_rebote.js` for bouncing with collisions.

No build tools or servers required – pure vanilla HTML/CSS/JS.
